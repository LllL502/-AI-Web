# 09 安装、运行与故障排查

## 1. 环境

- Windows 10/11 x64。
- Python 3.12、Node.js 24（Vite 要求 Node 20.19+ 或 22.12+）。
- 首次安装允许联网下载 Python/npm 依赖和 MySQL 8.4.11 便携 ZIP；安装后核心页面不依赖 CDN。

当前项目内 MySQL ZIP 已按官方发布页校验：`mysql-8.4.11-winx64.zip`，MD5 `2e833921898a9a030ea6bfe81bd811bc`（本机另算 SHA-256 `A492371D687D2BAB088B0062581144A0044B8964BAEFDF4FAA579292B423D25C`）。

## 2. 一键步骤

在 `campustrace` 目录双击或从 PowerShell 执行：

```powershell
scripts\setup.cmd
scripts\start.cmd
scripts\health.cmd
```

浏览器访问 `http://127.0.0.1:5173/`。停止时运行：

```powershell
scripts\stop.cmd
```

脚本不会创建系统服务：MySQL 仅监听 `127.0.0.1:3307`，数据保存在 `data/mysql/data/`；Django 仅监听 `127.0.0.1:8000`；Vite 仅监听 `127.0.0.1:5173`。

为避免 MySQL 在含中文的 Windows 项目路径下处理 InnoDB 文件异常，脚本会在用户临时目录建立 `CampusTrace-AIC8-Runtime` 目录联接。物理数据仍在项目的 `data/mysql/data/`；`stop.cmd` 只会在确认该路径是本项目联接时删除链接。

## 3. 公网测试版

首次使用需要联网安装 Waitress 并从 Cloudflare 官方发布页下载项目内 `cloudflared.exe`：

```powershell
scripts\setup-public-test.cmd
scripts\start-public-test.cmd
```

启动窗口会打印随机 `https://*.trycloudflare.com` 地址，同时写入 `artifacts/logs/public-test-url.txt`。任何人拿到链接都可浏览、注册普通用户并登录；电脑关机、网络断开或关闭启动窗口后链接失效，下次启动地址通常会变化。

启动后可运行 `scripts\smoke-public-test.cmd`，脚本会用临时普通用户验证公网首页、健康接口、注册、重新登录、Secure Cookie 和固定演示账号隔离，随后删除临时账号并写入 `artifacts/public-test-evidence.json`。

公网链路为 `Cloudflare HTTPS → Vite Preview 127.0.0.1:4173 → Waitress 127.0.0.1:8010 → MySQL 127.0.0.1:3307`。外部不能直接访问三个本地端口。停止时另开终端执行：

```powershell
scripts\stop-public-test.cmd
```

公网模式拒绝 `admin_demo`、`staff_east`、`staff_west` 与 `student_01`–`student_08` 全部固定演示凭据，只允许新注册普通用户登录；本地答辩模式不受影响。Quick Tunnel 是测试工具，不提供固定地址或生产可用性承诺。

## 4. 演示账户

固定种子首次创建以下本地账户，初始密码均为 `CampusTrace!2026`：

- `student_01`：普通用户。
- `staff_east`：东区/图书馆站点协调员。
- `staff_west`：西区/南门站点协调员。
- `admin_demo`：系统管理员。

这些是明确标记的演示账户，不应用于真实部署。真实试点前必须替换密码、密钥和用户接入机制。

## 5. 常见问题

- **MySQL 启动超时**：查看 `artifacts/logs/mysql.stderr.log`；确认 3307 未被占用。
- **前端无法加载数据**：运行 `scripts/health.cmd`，再查看 backend/frontend stderr 日志。
- **数据已存在**：`seed_demo` 默认拒绝覆盖；确认只需重建演示数据后使用 `seed_demo --reset-demo`。
- **Vite 构建 spawn EPERM**：某些沙箱阻止内部构建子进程；在普通 PowerShell 执行 `npm run build`。
- **WebGL 不可用**：页面会自动显示等价二维热点/候选列表，不影响核心办理流程。
- **公网地址无法打开**：确认 `start-public-test.cmd` 窗口仍在、`public-tunnel.stderr.log` 中连接检查为 PASS，并重新读取 `public-test-url.txt`。
- **公网地址发生变化**：Quick Tunnel 每次启动生成随机地址，属于预期行为；固定域名需升级为 Cloudflare 受管隧道或服务器部署。

## 6. 验证命令

```powershell
cd backend
.venv\Scripts\python.exe manage.py check
.venv\Scripts\python.exe -m pytest tests -p no:cacheprovider -q
.venv\Scripts\python.exe manage.py evaluate_demo
.venv\Scripts\python.exe manage.py import_schools

cd ..\frontend
npm run build
npm run test:e2e
```

Playwright 使用本机 Microsoft Edge，运行前必须保持 `start.cmd` 启动的三项服务健康。

学校目录导入使用项目内教育部官方附件，`import_schools` 可重复运行，按学校标识码更新并保留已有校区。该命令不创建未核实校区。目录API及顶部搜索面板更新后，重新启动本地或公网后端进程。
