## 校区来源与限制

本轮未找到覆盖全国、公开下载且可作为权威基准的完整校区总表。教育部高校名单不应被解释为校区名录。逐校优先核对学校官方简介、校园地图、招生章程、信息公开及最新校区公告。新建、在建、停用、研究基地和附属机构须区分，不把每个地图 POI 视为校区。

第三方检索线索：

- https://github.com/ZsTs119/china-university-database ：自述来自百度地图 API 的高校地理位置数据。
- https://github.com/pg7go/The-Location-Data-of-Schools-in-China ：自述包含分校区的地图位置数据。

上述来源仅供候选发现；本轮未审核许可、更新时间、坐标系、校区去重或覆盖率，不直接导入正式校区。坐标必须标注 WGS84/GCJ02/BD09 来源，避免地图偏移。

## 数据入库与前端规则

学校记录保存官方标识码、名称、省份/所在地、办学层次、数据来源与版本。拼音及首字母由名称生成，仅用于搜索；简称单独维护并核对，防止把西安交通大学与西南交通大学等混淆。

当前校区记录保存所属学校、名称、来源链接、核对日期以及VERIFIED/UNVERIFIED状态。用户反馈另用PENDING/APPROVED/REJECTED状态。按后续用户要求，未核实学校提供标为UNVERIFIED的“主校区”临时容器，并可提交纠错；该容器不计入已核实覆盖数，也不能当作实际地理位置。

交付日前建议完成全国普通高校官方名录解析、名称/首字母搜索与学校-校区联动，校区先覆盖有官方证据的学校并公开显示覆盖范围。后续通过资料补充申请和人工核对扩展，不能声称短期已核实全国所有校区。
