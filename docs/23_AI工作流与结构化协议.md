# 23 AI 工作流与结构化协议

## 1. 当前实现边界

寻迹 AI 助手已建立第一版可运行骨架：

1. 严格结构化协议，拒绝未声明字段、非法枚举和越界长度。
2. 提供方适配层，支持明示的本地规则桩和通用 OpenAI-compatible JSON 输出。
3. 结构化字段必须带原文片段，服务端会检查片段确实存在于脱敏后原文。
4. 公开描述强制使用服务端脱敏后的用户原文，不接受模型补写的事实。
5. 只读工具白名单：查公开物品、读公开详情、查服务站、生成不落库的待确认草稿。
6. 前端已提供执行阶段、取消、20 秒超时、重试、可编辑确认卡和普通表单兜底。

当前候选召回仍是同校区真实公开记录上的关键词检索，接口会明确返回 `semantic_retrieval: false`。它不得在演示或文档中被称为已完成语义 RAG 或图片检索。

## 2. 提供方模式

| `AI_PROVIDER_MODE` | 行为 | 是否外部调用 | 前端标识 |
|---|---|---:|---|
| `development_stub` | 本地确定性规则桩，用于协议、UI 和测试 | 否 | 必须显示“开发模式，不是真实大模型输出” |
| `openai_compatible` | 向配置的 `/chat/completions` 发送 JSON 请求 | 是 | 显示实际适配器和模型名 |
| `disabled` | 返回 503 并引导到普通表单 | 否 | 不显示伪造结果 |

默认值为 `development_stub`。真实密钥只能放在本机未跟踪的 `backend/.env` 或部署平台密钥管理中，不得放入 `.env.example`、README、测试、截图或 Git 历史。

```env
AI_PROVIDER_MODE=openai_compatible
AI_PROVIDER_BASE_URL=https://provider.example/v1
AI_PROVIDER_API_KEY=
AI_PROVIDER_MODEL=
AI_REQUEST_TIMEOUT_SECONDS=20
AI_MAX_INPUT_CHARS=1200
```

HTTP 地址只在 Django `DEBUG=true` 且主机为 `127.0.0.1`/`localhost` 时允许，用于本机模型服务；其他提供方必须使用 HTTPS。

## 3. HTTP 接口

### `GET /api/v1/assistant/capabilities/`

返回提供方模式、是否模拟、当前输入能力、工具白名单和安全边界。不返回提供方 URL 或密钥。

### `POST /api/v1/assistant/prepare/`

需登录。输入：

```json
{
  "kind": "LOST",
  "description": "昨天晚上可能在图书馆丢了一副黑色 Sony 耳机"
}
```

返回：

- `provider.simulated`：是否为开发规则桩。
- `stages`：真实执行阶段；未执行的检索和解释标记为 `blocked`。
- `draft`：结构化待确认草稿。
- `follow_up_questions`：最多 3 个、可跳过的动态补问。

该接口不创建物品、不提交审核、不启动认领。

### `POST /api/v1/assistant/search/`

需登录。接收用户编辑后的完整 `draft`，然后：

1. 从 `X-Campus-ID` 确定当前校区。
2. 只查 `APPROVED + OPEN` 的相反类型物品。
3. 返回显式公开字段，不使用登录态 `ItemSerializer` 暴露本人或工作人员可见的私密字段。
4. 为每个候选返回 `citation_id=item:<uuid>` 和可打开原始记录的 URL。
5. 同时返回当前校区已审批且开放的服务站。

候选为空时返回明确空结果，不生成虚构物品或理由。

### `POST /api/v1/assistant/draft-preview/`

需登录。复用现有 `ItemSerializer` 的校区、类别、地点、服务站和字段规则，但不调用 `save`。固定返回：

```json
{
  "persisted": false,
  "requires_user_confirmation": true
}
```

用户确认后仍必须走现有发布、审核、认领和交接业务接口。

## 4. 工具权限表

| 工具 | 读写性质 | 服务端限制 |
|---|---|---|
| `query_public_items` | 只读 | 当前校区、已公开、业务状态为开放、最多 10 条 |
| `read_public_item` | 只读 | 只返回显式公开字段和公开图片 |
| `query_service_stations` | 只读 | 当前校区、已审批、开放、有效 |
| `generate_pending_draft` | 只读 | 仅验证，不落库，必须再由用户确认 |

白名单中故意没有 `approve_claim`、`delete_item`、`complete_handover` 或类似工具。以后接入真实 Function Calling 时，也只能将模型调用映射到此白名单，且每次执行前由服务端重新验证参数和权限。
