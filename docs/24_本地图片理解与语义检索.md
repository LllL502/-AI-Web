# 本地图片理解与语义检索

## 已实现及尚待验证

图片入口 `/assistant/image/` 接收 JPEG/PNG/WebP，实际解码验证、限制 8MB / 2000万像素、移除 EXIF 并缩放后发送给本机视觉模型。模型观察经脱敏后必须由用户核对，才会加入描述；图片不会自动创建业务记录或写入媒体库。

检索配置本地 embedding 服务后，使用真实模型向量与余弦相似度排序。先过滤校区、公开审核与开放状态，再读取公开描述。最新实现已使用数据库持久索引并移除500条限制；按公开内容哈希和模型修订更新，批量16条。详见docs/29_持久向量索引与增量维护.md。它是“图片转描述→人工核对→文本向量检索”，尚不是图像与文本共享空间的直接图片相似检索。

本机已安装项目级 Ollama 0.40.16，绑定 `127.0.0.1:11435`，关闭云端推理。模型选择为 `qwen3-vl:4b-instruct`（图片理解与文字提取）和 `qwen3-embedding:0.6b`（语义向量）。真实端到端验收结果以 `artifacts/local-ai-verification.json` 为准。不能把接口测试通过当作模型效果验证。未配置向量服务时保留明示关键词检索；配置后服务失败会报错，不伪装为语义检索成功。

## 配置

在 backend/.env 中填写实际本机 OpenAI-compatible 服务（URL包含 `/v1`）：

```dotenv
AI_PROVIDER_MODE=openai_compatible
AI_PROVIDER_BASE_URL=http://127.0.0.1:11435/v1
AI_PROVIDER_API_KEY=ollama-local-placeholder
AI_PROVIDER_MODEL=qwen3-vl:4b-instruct
AI_REQUEST_TIMEOUT_SECONDS=90
AI_LOCAL_VISION_URL=http://127.0.0.1:11435/v1
AI_LOCAL_VISION_MODEL=qwen3-vl:4b-instruct
AI_LOCAL_EMBEDDING_URL=http://127.0.0.1:11435/v1
AI_LOCAL_EMBEDDING_MODEL=qwen3-embedding:0.6b
```

视觉服务必须支持 `/chat/completions` 的 image_url data URI；向量服务必须支持 `/embeddings` 的批量 input 与 index 字段。仅允许 loopback HTTP，应用不向云端发送这些图片或向量请求。

`ollama-local-placeholder` 只是本机兼容接口占位值，不是付费密钥。本机配置不调用外部推理 API。

## 启停和安装复现

日常运行原来的 `scripts/start.cmd`，会自动启动已安装的本地 AI。`scripts/stop.cmd` 会停止本项目服务。也可以分别运行 `scripts/start-local-ai.cmd` / `scripts/stop-local-ai.cmd`。

程序位于 `tools/ollama/`，模型位于 `data/local-models/`，物理位置均在 D 盘项目目录；不修改系统 PATH，不创建 Windows 服务或开机启动项。首次下载需要网络；模型完整下载后推理可离线运行。脚本沿用当前已启用的本机代理下载，不更改系统网络配置。

安装复现：运行 `backend/.venv/Scripts/python.exe scripts/download-local-ai.py`，再运行 `scripts/install-local-ai.ps1`、`scripts/start-local-ai.ps1`、`scripts/pull-local-models.ps1`。运行包 SHA-256：`50fcf5ad54277f2fa5d173ebfc93bcb017adbc0c9ef2314daabc96ca9e6aa64e`，来源为官方 0.40.16 发布校验清单。

来源：[Ollama Windows](https://github.com/ollama/ollama/blob/main/docs/windows.mdx)、[视觉模型](https://ollama.com/library/qwen3-vl:4b-instruct)、[向量模型](https://ollama.com/library/qwen3-embedding:0.6b)、[兼容接口](https://docs.ollama.com/api/openai-compatibility)。

## 真实服务验收

`verify_local_ai` 已通过5项真实推理检查（两张图、同义改写向量比较、演示库召回、文字结构化）。该次运行中图片描述耗时为3.06秒和2.03秒；同义描述余弦相似度0.7023，雨伞对照0.3436；演示检索首位是黑色蓝牙耳机。耗时只代表这台机器上的该次样例，不代表并发性能。

可复现命令：在backend运行 `.venv/Scripts/python.exe manage.py verify_local_ai`。结果保存在 `artifacts/local-ai-verification.json`。真实浏览器流程可用 `CAMPUSTRACE_REAL_LOCAL_AI=1` 运行 `frontend/tests/e2e/local-ai.spec.ts`，需保持本地服务运行。

2026-11-13真实浏览器流程已通过：登录演示账号、上传耳机图、本地识别、人工确认、结构化提取、真实语义候选。最终补跑用时15.4秒，已核对无图卡片布局和配图标注。截图为 `artifacts/local-ai-browser-demo.png`。相关后端10项测试通过，前端41项测试通过，最终类型检查和生产构建通过；一键停止/启动后数据库、API、网页健康检查均通过。

图像观察存在细节误判（例如划痕位置），因此保留人工核对，不能自动认领。仍需扩展真实授权样本、困难负例、无图和模型中断案例，以及与旧六因子方案的统一对比；不宣称真实识别率或找回率。

Windows目录联接会影响本机模型清单读取，启动脚本自动定位D盘物理模型目录，不让模型依赖临时运行联接。数据库停机脚本等待进程完全退出后再卸载临时路径，避免关闭期间的数据文件锁冲突。
