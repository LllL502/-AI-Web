# 学校与校区隔离

学校 School 下设多个 Campus；CampusLocation 必须归属一个校区。物品通过 location.campus 确定校区，服务站通过 location.campus 确定校区，避免重复存储归属字段产生不一致。

西安交通大学登记兴庆、雁塔、曲江、中国西部科技创新港四个校区。名称依据学校官方资料： https://nic.xjtu.edu.cn/info/1017/6064.htm 。本次只建立组织目录，未虚构真实地点、服务站或学校授权。

迁移 0002 将全部旧地点归入独立“演示学校 / 演示校区”。交大四校区初始为空，保留原有 360 条演示物品、站点和流程数据。

前端导航栏可选择学校与校区，浏览器保存选择并在 API 请求发送 X-Campus-ID。后端同时支持 campus 查询参数；无参数时使用演示校区以兼容既有演示与测试，无效校区返回 400。校区选择不授予角色或站点权限。

已隔离物品列表/详情/编辑、地点与站点元数据、地图聚合、公开/后台站点、后台物品与认领统计、举报、收藏、认领和匹配运行。跨校区物品 ID 返回 404；写入地点必须属于当前校区，服务站必须与地点同校区；认领关联和预约交接禁止跨校区。匹配索引仅使用查询物品同校区的候选，防止文本相似度产生跨校区误匹配。

用户账号、个人通知、订阅设置、帮助内容、算法配置和系统任务仍是平台级资源；管理权限依旧由角色与站点成员关系控制。此次未实现学校独立管理员体系或校区订阅推送。

验证：后端原有 31 项与跨校区读写/认领 2 项全量通过；另有匹配索引隔离测试。生产前端类型和 699 模块构建通过。数据库迁移已应用，旧数据保留。

运行中的后端进程不会自动加载新模型和规则。更新公网版本时停止再启动 public-test 脚本；新的随机公网地址以启动窗口输出为准。下一步录入经核对的兴庆校区地点，随后接入真实地图。
