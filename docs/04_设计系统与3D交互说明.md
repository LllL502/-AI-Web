# 04 设计系统与 3D 交互说明

## 1. 视觉方向

设计关键词为“夜色校园、温暖拾光、可信证据”。底色使用深靛蓝与低饱和雾蓝，关键行动采用暖金色，成功、警告、危险均保留文字和图标，不单靠颜色传递状态。正文保持高对比和稳定行长，卡片层级以边框、微光与空间关系表达，避免装饰堆叠。

## 3. 三处真实 Three.js 场景

| 场景 | 页面 | 可操作内容 | 可访问回退 |
|---|---|---|---|
| 校园微缩 | P01 首页 | 拖拽旋转、缩放、热点聚焦、统计联动 | 同等热点的 2D 校园卡片网格 |
| 校园线索地图 | P12 | 区域选择、图层筛选、线索聚合、定位复位 | SVG/HTML 2D 地图与列表联动 |
| 匹配关系解释 | P11 | 查看两物品节点、六因子证据边、缺失因子 | 因子条形图与证据表 |

三处场景都必须具有独立生命周期：进入路由时初始化，离开时取消动画帧、事件监听并释放 geometry/material/texture/renderer；WebGL 初始化失败时自动切换回退界面。不得用静态背景视频或截图冒充交互场景。

## 4. 动效与性能

- 首屏不等待 Three.js 才呈现核心文字和操作；场景按路由异步加载。
- `prefers-reduced-motion: reduce` 时停止持续旋转、粒子漂移和非必要视差，保留即时状态反馈。
- ResizeObserver 驱动尺寸更新，页面隐藏时暂停帧循环。
- 桌面和移动端均提供键盘可达的等价控制；Canvas 附带文本说明和回退入口。

## 5. 关键交互模式

- 发布表单：步骤可回退，自动草稿，离开提醒，服务端字段错误定位到对应步骤。
- 匹配结果：总分、覆盖率、六因子贡献、缺失原因、算法/索引版本必须同时可见。
- 高风险动作：审核决定、关闭物品、批准认领、交接确认使用明确后果说明和二次确认。
- 长任务：展示持久任务 ID、状态、进度与失败原因；刷新页面后仍可恢复，不使用仅存于内存的假进度。
