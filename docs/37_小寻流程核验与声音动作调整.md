# 小寻流程核验与声音动作调整

日期：2026年11月16日。结论：小寻可以在聊天内辅助学生完成寻物主流程；不能据此称为覆盖全站所有角色和任意自然语言命令的通用智能体。管理员运营、拾得者审核、另一方和工作人员的实际交接确认仍由相应角色办理。

## 核验范围

| 环节 | 核验结果与证据 |
|---|---|
| 文字描述、补充特征、真实候选检索 | 实际本地模型浏览器用例通过；耳机与粉色A4本子场景无需跳回表单，肯定词不混入描述 |
| 照片识别、用户核对、提取检索 | 发现并修复重复改写造成的协议错误；确认后的照片观察直接提取和检索，真实模型浏览器用例通过（12.5秒） |
| 发布、认领、补充私密证明 | 测试数据库执行真实服务；浏览器固定响应测试核验整条界面衔接和明确确认，未在演示库制造认领或给真实用户发送测试消息 |
| 双方直接交接 | 测试数据库分别模拟本人和拾得者，单方确认保持待交接，双边确认后完成 |
| 预约服务站、交接码、本人领取确认 | 补齐聊天内交接码核验与本人确认；真实服务测试和界面单元测试通过。错误码计数能提交，不受幂等事务回滚影响；仍需工作人员确认 |
| 继续已有认领、删除记录、重复请求 | 恢复待办可用；修复已隐藏记录仍能读取的问题；幂等重放重新读取当前认领状态，不再展示旧状态 |
| 站内沟通 | 修复小寻误用`/conversations/`地址的问题，改用网站实际的`/messages/`接口；恢复认领、读取消息和确认发送的前端单元测试通过，测试数据库参与者权限及实际消息提交接口测试通过。本轮未向真实用户发送测试消息 |
| 管理后台、原站点与账户页面 | 原有10项常规浏览器用例通过，管理模块可用；未把所有管理写操作开放给小寻 |

私密“核验特征：……”即使在未选择物品或恢复待办时输入，也被独立捕获，不进入通用模型上下文或公开描述。图片引用只允许来自真实用户原文；模型截取连续片段时恢复完整原话，避免截掉“不是”“不确定”。

## 声音

按用户最新要求调整为活泼童声风格：中文zh-CN，音调1.58、语速1.08、音量0.9。优先选择系统可用的中文童声音色，其次选择较轻快的中文音色进行偏童声调音；不强行选择英文声音。

这是浏览器及操作系统语音库上的角色化调音，不是新增独立TTS模型或已固定的机器人声线。实际音色及参数效果由浏览器语音引擎决定。浏览器测试验证了点击后才朗读及所用参数，没有把主观听感当作自动化测试结论。

## 动作与气泡

按用户最新澄清，只将挥手、wink、转圈的轮换间隔改为20秒，气泡保持55秒间隔，出现7秒后消失。动作与气泡独立调度，初次进入可见区域时一同打招呼；单次大动作约2.2—2.5秒，其余时间安静待机，仅保留轻微呼吸与自然眨眼。

首次进入可见区域时打招呼。离开屏幕、页面隐藏、正在聊天或正在办理请求时不主动开始新动作；打开聊天会结束当前气泡和姿态。尊重系统减少动态效果设置。无自动播音。
