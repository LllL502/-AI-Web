# 05 智能匹配算法说明

## 1. 八段职责

正式实现位于 `backend/apps/matching/engine.py`，明确分为：

1. `preprocess`：NFKC、大小写/空白/标点统一、校园别称、停用词与 jieba 分词；保留“不、没有、无、未、不是”。
2. `fit_index`：在所有合格公开候选上一次拟合词表和 IDF，生成 CSR 稀疏矩阵及真实倒排表。
3. `transform_query`：查询只使用已拟合索引的同一词表与 IDF，不单独重新拟合。
4. `generate_candidates`：按相反类型、审核通过和业务可用性过滤，并记录排除原因计数。
5. `compute_factors`：计算文本、类别、地点、时间、颜色、品牌六因子。
6. `rank`：按缺失感知公式评分、证据门槛分组并稳定排序。
7. `explain`：输出版本、覆盖率、有效权重、贡献、冲突、缺失项和公开词项贡献。
8. `evaluate`：在同一标注集合上计算 Precision@K、Recall@K、Hit@K 和 MRR。

## 2. TF-IDF 与余弦相似度

当词项出现次数 `count(t,d)>0` 时：

```text
TF(t,d)  = 1 + ln(count(t,d))
IDF(t)   = ln((1+N)/(1+df(t))) + 1
V(t,d)   = TF(t,d) × IDF(t)
V_norm(d)= V(d) / ||V(d)||₂
S_text   = cosine(V_norm(q), V_norm(d))
```

运行实现使用 `TfidfVectorizer(smooth_idf=True, sublinear_tf=True, norm="l2")` 和自定义中文 tokenizer。零向量保持零，文本因子标记缺失，不产生 NaN。单测中的独立 `reference_tfidf` 未调用 sklearn 的公式实现，用于检查相同数学口径。

## 3. 六因子与缺失感知

初始权重仅是可运行初值，不声明为实验最优：

| 因子 | 初始权重 | 实现 |
|---|---:|---|
| 文本 | 0.50 | 同一 TF-IDF 空间中的稀疏余弦 |
| 类别 | 0.15 | 同叶 1、同父 0.65、已知不同 0 |
| 地点 | 0.12 | 遗失方最多 5 个排序候选与拾获方单一地点对齐；同地点 1、同上级区域 0.65，再按候选顺序衰减 |
| 时间 | 0.10 | 遗失→拾取可行间隔 `exp(-Δt/τ)`，明确逆序记冲突 |
| 颜色 | 0.08 | 规范化多色集合 Jaccard |
| 品牌 | 0.05 | 词典别称后严格相同 1、已知不同 0、未知缺失 |

令 `mᵢ=1` 表示双方有可比较信息，否则为 0：

```text
coverage C = Σ(wᵢ × mᵢ)
score S    = Σ(wᵢ × mᵢ × Sᵢ) / C  (C>0)
display    = 100 × S
```

已知不一致以 `m=1, score=0` 参与，不能伪装成缺失。初始主推荐资格要求文本向量非零且覆盖度不低于 0.60；不满足者进入“信息不足，仅供浏览”。同分时依次按可操作性、分数、覆盖率、候选 ID 排序，结果可复现。

地点顺序衰减系数为 `[1.00, 0.80, 0.65, 0.50, 0.40]`。用户只表达“最可能到较可能”，不需要伪造精确概率。结构化地点采用校园层级对齐；真实地图候选采用 Haversine 距离与 250 米校园步行尺度指数衰减，2 公里外视为已知不同。所有候选为空时，地点因子标记为缺失并重新归一化其他因子，而不是记 0 分。

算术单测：`[0.80,1.00,0.75,0.90,1.00,0.00]` 全可用时为 81.00 分、覆盖度 1.00；品牌改为未知时覆盖度 0.95、分数约 85.2631579。

## 4. 输入隐私边界

`ItemFeature` 数据合同只包含公开文本、类别、颜色、品牌、事件时间、版本、状态，以及受保护的地点层级或坐标与顺序衰减值。坐标仅在服务端用于计算距离，匹配解释只输出约化距离和分数，不输出候选地点名称或原始坐标；自由文本位置不进入特征。手机号、私密答案、完整序列号、会话正文和认领结果标签在类型层面没有入口。图片仅用于展示和人工核验，本版本不声称 OCR、图像识别或深度学习能力。

## 5. 版本与复现

- `AlgorithmConfig`：权重、门槛、预处理和字典版本，草案不影响正式运行。
- `IndexVersion`：语料数量、词表大小、语料校验和与配置版本。
- `MatchRun`：查询物品、算法/索引版本、开始/结束时间和状态。
- `MatchCandidate`：因子快照、总分、覆盖率、解释与当时可用性。

历史报告读取保存的计算快照；当前物品已归还时，前端必须禁用认领动作，但不篡改历史分数。
