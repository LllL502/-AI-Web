# AI 发布内容整理与无图展示修复

日期：2026-11-16。

## 修复内容

1. 移除 `ItemVisual.vue` 按类别、颜色加载示例图片的兜底。记录没有公开照片、照片加载失败或地址不合法时，统一显示中性图标和“暂无实拍图”。已有记录上的真实媒体字段不变，演示数据原本附带的媒体也不会被当成新上传图片生成。
2. 原来的公开描述被服务端强制设置为用户整段原话，标题也截取原话。现在模型提取类别、颜色、品牌、外观短语、地点和时间，服务端检查引用后组织标题和描述。聊天包装、发布请求、情绪表达和联系方式不进入公开文案。
3. 新增 `appearance_details`：必须是原文里的外观短语，不接受编造的贴纸、划痕等特征；保留否定、不确定性，私密核验信息不进入此字段。颜色、品牌、地点等被否定时不作为确定事实。
4. 对话同时出现“捡到”“丢失”时暂停生成发布草稿，先澄清事件类型。回答后继续使用此前的外观、时间和地点，不因短答而遗忘。只有一种明确事件时按事件生成寻物或招领草稿。
5. 模糊时间保留原文，不把自然语言时间塞入日期字段；不能可靠确定日期时交给用户核对，不捏造精确时间。
6. 发布前可以核对并编辑类型、标题、物品描述、类别、地点和时间，确认后才提交。新一轮结果到来时关闭过期发布表单。

## 真实模型示例

输入：昨天晚上10点多，我在田径场捡到一副黑色耳机，充电盒盖有一道浅划痕，没有挂件。帮我发条招领吧，我有点赶时间。

整理出的标题：**拾到黑色耳机**。

描述保留黑色耳机、充电盒浅划痕、没有挂件、田径场和昨天晚上10点多，去掉“帮我发条招领吧”“赶时间”。没有照片时不自动生成或匹配示意照片。

运行结果：`artifacts/agent-publication-copy.json`；预览截图：`artifacts/agent-publication-copy-preview.png`。
