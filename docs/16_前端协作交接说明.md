# 拾光 CampusTrace 前端协作包

交接基线：2026-10-09，高德地图支持未核实校区按学校名称搜索。此包仅含前端源码、锁定依赖、测试与必要接口文档，不含后端、数据库、密钥、用户上传文件或 node_modules。

## 启动

安装 Node.js 22.12 或更高版本（建议 Node 22 的最新补丁版）。进入解压后的 `frontend`：

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。仅启动前端不代表完整业务可用：登录、学校列表、发布和匹配均依赖原项目 Django 后端。默认代理地址为 `http://127.0.0.1:8000`。

有经项目负责人授权的可访问后端时，可以在同一个 PowerShell 窗口设置：

```powershell
$env:CAMPUS_TRACE_API_TARGET='http://经授权的后端地址:端口'
npm run dev
```

不要随意指向正式数据库进行发布、审核、认领等操作。远程后端联调需要由负责人配置允许的 Host、可信 CSRF Origin 和 HTTPS Cookie 策略；改代理地址本身不能保证登录成功。临时公网前端链接也不能不加确认就当作 API 服务地址使用。

没有后端时，可用组件测试中的 API/高德 SDK 模拟作为设计调试参考；若增加 Mock，必须仅在明确的开发模式启用，并在交付时说明，不能替换实际业务接口。

## 可以改与必须保留的约定

可自由优化 `src/views` 页面、组件布局、CSS、响应式和动效。优先复用现有图标、颜色变量和组件；保持中文提示与键盘可访问性。

以下内容变更前必须与负责人协调：

- `/api/v1` 接口路径、请求字段、返回包结构及枚举。
- `src/api/client.ts` 的 Session Cookie、CSRF 和 `X-Campus-ID` 逻辑；不得靠删除权限验证让页面“能用”。
- 学校→校区联动，`campustrace-campus` 存储键，以及发布地点和校园隔离关系。
- 路由 URL、登录守卫、USER/STAFF/ADMIN 角色与受保护页面。
- 高德同源 `/_AMapService` 代理，不能在前端写 securityJsCode 或其他私密凭证。
- 精确位置、认领私密答案和审核信息的脱敏规则；不得把私密字段展示为公开卡片。

如需新接口、建筑/校区边界、后端返回新字段，请提交需求清单，不要擅自硬编码为已核实资料。

## 自测与交付

```powershell
npm run build
npm test
```

交接时基线：构建通过，前端单测 12 项通过。`npm run test:e2e` 还需要本地后端、对应演示数据和 Microsoft Edge；不能在真实用户环境直接跑会修改数据的端到端测试。旧版端到端报告不代表新版高德真实鉴权已验证。

检查：首页、学校校区切换、手机布局、登录注册、发布表单、列表详情、匹配中心；覆盖空数据、加载、失败、无密钥降级。高德未核实校区应显示提醒并仅按学校名称搜索。

请返还源码（不要只给 dist），包括变更过的 package.json / package-lock.json、测试及一份变更说明。排除 node_modules、dist、.env、缓存与真实业务数据。注明新增依赖、接口要求和未完成事项。

## 回迁方式——合并，不盲目覆盖

包内 `baseline-sha256.csv` 保存交接时前端文件哈希，用于确认共同基线。负责人这边也可能继续改前端：返还后先比较双方改动，合并冲突，再 `npm ci`、构建、单测、完整后端联调，最后重新发布。

只改视觉并遵守现有合同，通常无需重写后端；但不是保证“直接迁移就完全可用”。改字段、接口、路由、权限或依赖可能需要配套后端修改。不要直接用对方整个目录覆盖当前前端，以免丢失交接后的地图修复和业务更新。
