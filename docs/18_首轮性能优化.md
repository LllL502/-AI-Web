# 首轮性能优化（2026-10-10）

- 登录初始化并发去重、就绪后复用；移除 App 重复调用。公开路由后台查询登录状态，受保护页面和登录页仍等待权限状态。
- 校区切换不再 location.assign。先卸载旧校园页面，再站内导航首页，更新页面版本重新取数；会话和 SDK 脚本保留，不缓存私密业务响应。
- 已入库地图校区直接显示，无需每次重新搜索；无候选成功查询在当前面板实例内冷却五分钟，仍提供手动刷新。
- 公网启动在源码、配置、依赖清单的修改时间未晚于 dist/index.html 时复用构建；有变化或无构建则重新构建。文件删除或保留旧时间戳的外部覆盖不能由时间戳可靠检测，交接合并后应手动 npm run build。

不宣称性能提升百分比：尚未测量公网 P50/P95、首屏与地图耗时。高德网络、临时公网隧道和地图创建仍有成本。本轮未引入地图数据缓存、数据库索引或正式服务器迁移。后续以浏览器 Network/Performance 与后端请求日志决定下一轮优化。

前端交接包早于这些变更；合并外部前端时保留 auth、router、App、campus 和 CampusPicker 的最新逻辑。
