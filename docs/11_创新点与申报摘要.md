# 11 创新点与申报摘要

## 创新点 1：缺失感知的可解释六因子融合

传统教学示例往往把空字段当 0 分，或临时删除冲突字段抬高分数。本系统显式区分“未知”和“已知不一致”：未知不进入分母，已知冲突以 0 分参与；同时展示覆盖度、归一化权重、贡献和冲突。算法既能处理校园信息不完整的现实，又能让评审手工复核算术。

针对“遗失者往往不知道精确掉落点”的真实场景，系统允许按可能性排序选择最多 5 个受保护地点，与拾获方的单一已知地点进行层级对齐和顺序衰减。完全未知时地点因子退出评分，既不惩罚诚实留空，也不向公开页面泄露行踪。

## 创新点 2：索引、配置、结果三层版本快照

每次匹配绑定算法配置版本、字典版本、语料校验和与索引版本；候选保存当时的六因子解释。权重更新不会悄悄改写历史报告，做到结果可复现、变更可审计。

## 创新点 3：匹配不替代所有权核验

算法只缩小候选范围。业务层通过私密举证、人工审批、数据库唯一保留、限时限次交接码与双方确认完成闭环，使“智能推荐”与“安全归还”各司其职。

## 创新点 4：3D 只解释真实关系

首页校园微缩、线索地图和匹配关系台均由 Three.js 实时构建并可交互；节点大小/距离/连线只映射同一后端响应，明确标注示意，不冒充高维语义几何或精确导航。WebGL 失败时有等价二维操作路径。

## 创新点 5：证据化验收

项目设置 G01–G10 门禁，要求测试结果、页面清单、截图索引、实验文件和运行日志支撑 PASS；未运行即标记 NOT_RUN，外部依赖缺失即 BLOCKED。这一机制避免将路由占位、随机统计或未执行测试包装成完成成果。
