# 环境与复现

## 依赖与平台

- Python 3.12；Node.js 22.12+或24；MySQL 8.4。Node依赖以package-lock为准，使用npm ci。
- Windows完整本地AI验收使用RTX 4060 Laptop 8GB、32GB内存。全局模型并发保持1；本次不是多人压力测试。
- backend/requirements.lock为网站依赖，scripts/requirements.voice.lock为本机童声环境的包版本清单；CUDA与PyTorch必须匹配系统和显卡，不能直接把Windows CUDA wheel安装到Linux。
- 模型、数据库运行包、浏览器及GPU驱动需另行安装；源代码仓库不附带这些大文件。

## Windows完整演示

1. 从MySQL官方渠道下载mysql-8.4.11-winx64.zip，放在tools/mysql-8.4.11-winx64.zip。setup脚本会解压到tools/mysql-8.4.11-winx64。
2. 执行scripts/setup.cmd。本地脚本创建3307端口的开发数据库与确定性演示数据；已有数据先备份。本地数据库口令仅用于开发，不可复制到服务器。
3. 执行backend/.venv/Scripts/python.exe scripts/download-local-ai.py，再执行scripts/install-local-ai.ps1、scripts/start-local-ai.ps1、scripts/pull-local-models.ps1。
4. 把backend/.env.local-ai.example中的AI字段合并进backend/.env，保留自己的数据库、随机密钥与域名配置。
5. 童声可选：python -m venv tools/qwen-tts-env；在该环境安装与系统匹配的PyTorch CUDA运行时，再安装scripts/requirements.voice.lock对应的依赖，并执行scripts/download_xun_voice.py下载模型。
6. scripts/start.cmd启动网站、Ollama和已安装的童声；scripts/health.cmd应分别显示数据库、网页、API、对话、向量、图片、童声状态。

已安装模型：qwen3-vl:4b-instruct、qwen3-embedding:0.6b；童声目录data/local-voice/Qwen3-TTS-12Hz-1.7B-VoiceDesign。首次下载需网络，推理在本机进行。

## 不使用项目自带MySQL包

自行创建UTF8MB4数据库、应用账户及测试库权限；复制backend/.env.example，填写自己的连接参数。安装依赖后执行migrate、seed_demo；分别启动Django与Vite。测试需要MySQL，不自动切换SQLite。

## 复现命令

- 后端：在backend虚拟环境运行python -m pytest -q、python manage.py check。
- 前端：在frontend运行npm ci、npm test、npm run build。
- 浏览器：保持网站运行，npx playwright test tests/e2e/ten-fixes.spec.ts；此用例的写接口为模拟，业务接口另在隔离数据库验证。
- 真实本地模型：python manage.py verify_local_ai；索引维护：python manage.py build_ai_index --help。
- 固定检索评测：python manage.py evaluate_assistant_fixed --help。

## 生产边界

当前Docker Compose包含网站、数据库与Caddy，不自动部署GPU推理。云服务器必须另有模型服务；本机回环地址不能跨机器直接沿用。视觉与向量适配器仅接受本机HTTP，需要与后端共享可验证的回环环境。部署详情见docs/13_正式生产部署.md。

正式上线后需记录固定域名、HTTPS验证、各角色评审账号、AI就绪与真实推理、图片授权及备份恢复结果。当前这些服务器验收项尚未完成，不能把本地健康检查填为服务器验收。

## 重建技术文档

安装scripts/requirements.docs.lock后，运行python scripts/build_submission_pdf.py。默认使用Windows中文字体；其他系统通过CAMPUS_TRACE_CJK_FONT与CAMPUS_TRACE_CJK_BOLD_FONT指定有权使用的TrueType中文字体。PDF需重新渲染逐页检查；字体文件不随仓库再分发。

### 本机已验证的童声依赖安装形式

在Python 3.12的tools/qwen-tts-env环境中，先按显卡驱动安装torch==2.6.0+cu124（官方CUDA 12.4索引），再使用该环境python -m pip install -r scripts/requirements.voice.lock，最后下载Qwen3-TTS权重。CPU或其他系统需选择各自支持的PyTorch构建；当前童声服务器使用CUDA生成，不能把CPU环境当作已验证配置。
