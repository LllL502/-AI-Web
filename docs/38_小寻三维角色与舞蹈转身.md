# 小寻三维角色与舞蹈转身

按2026年11月16日用户反馈，将小寻改为实际Three.js网格角色。头壳、身体、侧耳、手臂、手掌和短脚均具有三维厚度；背部新增外壳面板与通风细节。没有使用整张角色图或DOM元素绕Y轴翻转模拟转身。

转圈时在世界坐标中驱动角色根节点完成360度旋转，配合身体轻跳、左右迈步、手臂展开及头部平衡。单次转圈约2.8秒，结束回到正面；挥手和wink继续由20秒动作调度控制，气泡保持55秒间隔，原聊天功能不变。

采用透明背景、正交镜头和立体照明，渲染上限约30帧/秒，设备像素比上限2。角色离开可见区域或页面隐藏时停止绘制；尊重系统减少动态效果设置，组件销毁时释放几何体、材质和WebGL资源。图形库按需加载，复用现有three依赖。

设备无法使用WebGL时提供静态/轻动作矢量回退，不再显示平面翻转。回退图不等同于三维角色。

验证：56项前端单元测试通过，包含真实三维旋转、手脚关节、背部结构、减少动态效果和共享资源清理；3项浏览器测试通过，覆盖桌面、手机及实际WebGL正反面转身，确认页面和角色DOM本身的transform为none；正式构建通过。
