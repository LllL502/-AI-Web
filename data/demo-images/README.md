# 合成演示素材

这些素材由内置图片生成工具生成，只用于演示学校 / 演示校区的 is_demo 记录。
不是实拍证据，不用于证明物品归属。同一外观素材可用于多条构造记录。

- black-earbuds.png：黑色入耳式无线耳机与打开的充电盒，盒盖有细划痕，浅木色图书馆桌面，无品牌标识。
- black-umbrella.png：收拢的黑色折叠伞，伞柄带短挂绳，浅灰色桌面，无品牌标识。

生成提示：写实手机近拍、自然光、单件校园失物、无人、无文字、无水印、无品牌。
分别以以上外观描述生成，不能将素材中的背景作为实际遗失地点。

附图命令：`backend/.venv/Scripts/python.exe backend/manage.py attach_demo_images`。
只补齐外观匹配且没有任何媒体的演示记录，不修改标题、描述、认领或审核状态。
